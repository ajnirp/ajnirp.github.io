Maximum nested paren depth in APL

Aug 01 2026

Let's solve a Leetcode problem in APL. This blog post is inspired by this code report video. Given a valid parentheses string s, return the nesting depth of s. The nesting depth is the maximum number of nested parentheses.

My approach:

{⌈⌿+\¯1+2×'('=⍵∩'()'}

An example of calling this function:

      {⌈⌿+\¯1+2×'('=⍵∩'()'} '(())(()(()))'
3

In plain language:

  1. Discard all non-paren characters.
  2. Create a mask of ( characters.
  3. Multiply by 2 and subtract 1 to get a mask of 1 and ¯1 instead of 1 and 0.
  4. Return the maximum prefix sum.

The idea is we increment the depth when we see a (, decrement it when we see a ), and look for the maximum value we attain at any point. The runtime is linear because each of the above steps is linear. Note that the idiom +\ is optimized by the compiler to run in linear time, while scanning in general is quadratic (see this video by Richard Park for more discussion).

I also quite like the trick in step 3 in which we convert a Boolean mask to a mask of 1 and ¯1. The video mentions another a way to do it: the fork (⊢-~), which simply subtracts from a mask its negation, yielding the same result. We can compare the runtimes of the two approaches.
